# Pet Game

## Art Constraints
 * monochromatic
 * compositions of simple shapes (all circles, all triangles, etc.)

## Gameplay
 * virtual pet style game
 * three needs which decrease over time e.g. (hunger, cleanliness, exercise)
 * three buttons which satisfy those needs (feed, clean, play)

## Design
 * consider a "pet that isn't a pet"
